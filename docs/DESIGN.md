# Prism / 视觉语言

手机上的模型实验台，不是一个缩小的管理后台。

## 色彩

| Token | 颜色 | 用途 |
| --- | --- | --- |
| Deep water | `#101F2B` | 主背景、图片背景 |
| Slate glass | `#192C39` | 控制与结果卡片 |
| Quiet edge | `#2F4552` | 细边框与分隔线 |
| Mist | `#EFF6F6` | 主文字 |
| Tide | `#8DE2D5` | 当前模式、选中等级、主操作 |
| Dawn | `#EDB5A1` | 棱镜折射、缓存/故障提示 |

## 字体与版式

- 展示：sans-serif-medium，中文大标题与小写 `prism` 字标。
- 内容：系统 sans-serif，清楚的中文可读性，低对比辅助标签。
- 数据：monospace，用于模型 ID、任务 ID、等级与协议标签。
- 24dp 页面边距，20dp 卡片内边距，24dp 卡片圆角；平板内容最大 680dp。
- 触摸操作至少 48dp；底部导航与系统手势安全区分离，键盘区域不遮挡内容。

## Signature

棱镜把一个输入分成文字、图片和视觉理解三个出口。品牌图形由原生 Canvas 绘制：青色/珊瑚色双面棱镜与静态轨道。图形只在品牌和空状态出现，周围界面保持安静，避免把测试工具装饰成复杂科幻仪表盘。

## 页面

- **创作**：模式 → 模型 → 服务动态等级 → 提示词/参考图片 → 提交。
- **任务**：实际请求与状态、使用模型、可复制/分享/保存的结果。
- **连接**：完整 Base URL、隐藏 Token 输入、目录缓存与手动刷新、本机数据管理。

错误提示直接说明用户下一步该做什么；本地缓存、服务降级、演示模式明确区分。无自动播放、闪烁或持续装饰动画。
